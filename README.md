Personal [vis](https://github.com/martanne/vis) configuration.

Features:
- Copy to system clipboard with y
- Paste with Ctrl + V
- Open the manual with Shift + K, close it with q

## Dependencies

- vis >= 0.9 
- Language servers: `clangd`, ,  ecc...
- Manuals: `man`, `cppman`, ecc...

if you wanna add your language manual, just add it to the plugins/manual.lua file.

## Install
It's a personal repo but if you wanna use it, just simply clone the repo into the vis config folder.

## Plugin used

- [vis-plug](https://github.com/erikw/vis-plug) – Plugin manager
- [vis-autoclose](https://github.com/erikw/vis-autoclose) – Auto-close brackets
- [vis-lspc](https://github.com/alexherbo2/vis-lspc) – LSP client
- [vis-cursors](https://github.com/erikw/vis-cursors) – Multiple cursors
